# Workbench documentation

`55_Workbench/` within `spencerskelly/Test_Vault_` is the proposed consolidated implementation and product-definition space for MDSE Workbench. The former standalone Git repository retains historical provenance pending approved archival.

- `Definition/` — product definition, decisions, architecture and roadmap.
- `Testing/` — human-facing Workbench test material.
- `Reference/` — reference-plugin research and implementation evidence.
- repository root source/tests — executable implementation and automated tests.

Shared MDSE model semantics and cross-tool governance remain authoritative in `spencerskelly/Test_Vault_`.
