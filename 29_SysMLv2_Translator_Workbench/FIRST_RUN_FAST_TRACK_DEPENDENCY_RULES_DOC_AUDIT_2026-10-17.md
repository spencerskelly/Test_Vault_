# MDSE SysML v2 — First-Run Fast Track and Dependency Audit
**Audit date:** 2026-10-17  
**Status:** Reviewed current main source contracts and available test evidence; some checks still require a full local checkout, a compiled Obsidian plugin, and a real BOM assembly workbook. **No native v2 import acceptance claimed.**
**Goal:** Short, recoverable work passes with tangible output, leading to a disposable base vault with the reduced QEAX and one actual assembly BOM tested independently.

## Fast-path strategy
1. **Reuse what already works.** Original EA v0.8.19 HTML ingestion has evidence for a deterministic full-model v1/MDSE import (35,969 objects, 21,822 connectors) on its pinned September 2026 source. That is proof of its **source reader and staged-write experience**, not proof of v2 output. Preserve v1 stable release and add v2 translator profiles without modifying original semantics.
2. **Repair the release chain first.** The consolidated repo uses numbered folders; the release YAML, base builder, release checker, and several active workflows still reference old unnumbered paths. Fix paths and test run commands before attempting a broad import or promoting plugin versions.
3. **Two acceptance tiers:** (a) a small, independently parsed native SysML v2 **smoke test** plus source-preserving reports, then (b) a complete **reduced-QEAX diagnostic import** with one disposition per element/connector. Do not demand every legacy connector be native before a safe first viewing, but do not call a primarily deferred/flagged import a validated golden model. Disposition coverage is distinct from native conformance.
4. **Protect originals:** offline single-file HTML; real QEAX and BOM bytes, private row ledgers and imported model notes stay **local only**. Fresh uninitialized base copies. No import into Test_Vault_ main, no overwrite, no automatic EA/BOM merge, dry-run default.
5. **Build one first-run evidence package:** importer HTML + embedded rules digest + generated fresh-base ZIP + released plugin lock/binaries + local source diagnostics + validation checklist. Only method/code/tests and aggregate summaries are committed to GitHub.

## Documentation precedence — avoid mixed v1/v2 authority
1. **Approved user decisions** (2026-10-17) govern bottom native section, note-authoritative semantics, dropdowns, popup, independent EA/BOM UIDs, diagnostics and offline importer.
2. **V2 implementation contracts**: `14_Workbench/docs/SYSML_V2_BUILD_READINESS_STABILITY_UX_GATE_2026-10-17.md` **superseding addenda**, `14_Workbench/docs/GOLDEN_IMPORT_PREEXECUTION_GATE_AND_WORKBENCH_MENUS_2026-10-17.md`, `11_Importer/Definition/SysML v2 Single File Importers UID and Diagnostics Contract 2026-10-17.md`, `26_Definitions/V2 Delivery Plan.md`.
3. **V2 mappings/registry**: approved semantic mapping docs, typed evidence/normalization registry and synthetic tests. A proposal is not executable authority until governance and a test match.
4. **V1 compatibility**: `99_System/03_Schemas/*`, ruleset 1.23 and v0.8.19 are the historical implementation baseline for reusable source ingress and Bootstrap, **not** an alternate v2 source of truth. Do not rewrite existing v1 vaults.
5. **Historical/proposed**: `26_Definitions/SysML Source Ownership and Note Storage.md` and earlier workbench readme contain examples superseded by the approved bottom-of-note convention; annotate rather than delete historical rationale.

## 3 checkpoints, so the first experience is useful quickly
- **Checkpoint A — dependency repair:** passes 01–04; existing base chain can be built/tested without guessing paths, version or source shape.
- **Checkpoint B — visible smoke import:** passes 05–12; a tiny native fixture generates Markdown, opens in Obsidian, bootstrap verifies, popup navigates. Unsupported native editing is disabled, not broken.
- **Checkpoint C — real dual-source import:** passes 13–16; reduced QEAX and actual BOM into **separate fresh bases**, exhaustive source outcomes, independently parsed native output, repeatability and inspectable errors.

## First-run stop policy
Do not claim a successful native golden import while parser acceptance is zero, source rows are unaccounted for, hidden diagnostics exist, plugin lock fails, or a legacy release is mislabeled v2. Keep `flagLink` explicit and visible; never force all ambiguous connectors into fabricated native constructs simply to achieve a pass. An early **diagnostic import** with review queues is valuable, but must be labeled provisional.
