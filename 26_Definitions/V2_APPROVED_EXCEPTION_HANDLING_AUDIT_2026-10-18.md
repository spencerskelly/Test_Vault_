### Definition of gap
`selector_missing` = candidate cannot be matched. `evidence_missing` = family is approved but a specific row lacks the required source facts. `implementation_missing` = approved rule has no code path. `conformance_unverified` = code path exists but native/parser/Workbench tests absent. `extension_schema_pending` = the MDSE-only review/provenance model lacks approved storage implementation.

**Do not equate the older 32 provisional selector misses with 32 missing semantic decisions.** The 60-family approved review catalog already specifies those semantics. Fix exact implementation/exception rules and validate at source-row level instead of redoing connector review.

### Next work
- Create an approved-version (distinct from pinned provisional) rule registry resolving exact EA family then explicitly validated exceptions; refuse unrelated wildcard fallback.
- Negative and positive test cases for all EXC-01–EXC-12 using the approved source family and trusted endpoint direction.
- Parser testing for emitted use case/occurrence and feature usage; keep standard library causation separate.
- Connect `reviewFlags` (elements) and `flagLink` (relationships) through one governed review UI and schema without claiming these are SysML relations.
