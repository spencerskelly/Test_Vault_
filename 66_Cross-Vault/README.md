# Cross-Vault

Cross-vault resolution is intentionally deferred during the v0.8 golden-model effort, but it remains a planned MDSE capability.

- **History/** retains the previous resolver/plugin work as implementation evidence.
- No archived resolver is part of the current runtime.
- New cross-vault work should start here (or move to its own repository by explicit decision) rather than returning to a generic System plugin folder.
- Workbench's common `ModelRef` boundary must remain compatible with future cross-vault identity/resolution.
