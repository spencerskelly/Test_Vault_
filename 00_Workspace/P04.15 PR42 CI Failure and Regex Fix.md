## Root cause and correction

The classifier used Python raw regex `(?:&|\\\\*|!!)[A-Za-z_]` (two backslashes before `*`). Under Python regex interpretation the branch `\\\\*` can match zero backslashes, so ordinary alphabetic field values were erroneously treated as YAML aliases and rejected. Replaced with unambiguous character class `(?:&|[*]|!!)[A-Za-z_]`; it only matches explicit anchor, asterisk/alias or tag markers in the intended conservative context.
