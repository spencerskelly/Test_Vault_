# MDSE Tool-Development Workspace

This folder holds **cross-tool working authority** for the MDSE toolchain: current state, roadmap, cross-tool boundaries, release reconciliation, workspace decisions and handoff material.

It does not own executable tool implementations. Those live with the tool that owns them:
- Workbench: `spencerskelly/MDSE_Workbench`
- Importer: `Importer/`
- Bootstrap: `Bootstrap/`
- Base Vault/release tooling: `Base Vault/`
- deferred cross-vault work: `Cross-Vault/`
