## Important migration rule

A first-class Port note is not automatically a Local Model Interface occurrence. Define explicit owner, local ID, definition, multiplicity, endpoints, Item Flow target and direction in migration plan; preserve source identity and links. Unresolvable old links remain **review-only** rather than silently dropped or converted. Historical immutable notes may remain readable as legacy notes rather than being eagerly rewritten.
