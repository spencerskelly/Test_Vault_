# Enabled Plugin Stack

Controlled plugin release for MDSE vaults (W-322). Every plugin below ships **inside** the base vault, pinned and hashed in `.obsidian/plugin-lock.yaml`, enabled by `.obsidian/community-plugins.json`, and configured where noted. A person opens the vault, turns off Restricted mode (**Trust author and enable plugins**) and has the full stack. Nobody installs or updates plugins on their own machine; MDSE Bootstrap reports any difference from the lock.

Obsidian **1.13.0 or later** is required (`obsidianMinVersion` in the lock; set by Advanced Canvas, Breadcrumbs, QuickAdd and Templater).

Governed settings are generated by `build-plugin-config.py` from the schemas and tracked in Git; editing them in Obsidian shows up as a Git change. Per-machine and per-person state (`author-code.txt`, Workbench and Bootstrap `data.json`, `Workbench Views/`, defaults-only plugins' `data.json`) is git-ignored.

## Core plugins

Required on: Bases, Canvas, Properties, File explorer, Command palette (also enabled: search, graph, backlinks, outline, file recovery, bookmarks, tags, quick switcher). **Core Templates is off**: it would insert Templater syntax without running it. Use **Templater: Create new note from template**.

## Fileclass configuration

- Class files folder `99_System/06_Fileclasses/`, one generated note per class in `element-types.yaml`. Do not add other notes there: every note in that folder is read as a class.
- Binding by the note's `type` (Fileclass alias = `type`), so no `fileClass` property is written.
- Fields: `id`, `uid`, `subtype` (choices from `element-types.yaml`), `status` (Draft / Active / Retired, the values in use), then the relationship fields the class may author, in `relationships.yaml` order. Inverse fields are not offered (they are written by the translator, Workbench or the regenerate script); temporary translator-only fields `hasClassifier` and `equals` are not offered.
- Link candidates come from `MDSE Link Targets.base`: one view per allowed target-type set, including `excludePairs` and `sameClass`.
- Fields are not inserted automatically into notes (`insertFieldsOnBind` off), so property order stays as the templates write it.

## Deferred / historical

Ampure Cross-Vault Resolver and Multi-Vault Navigator were removed when the model returned to a single-vault design. MDSE Bootstrap 0.2.0, pinned before W-321, never existed; 0.3.0 is the implementation (W-322).

## Packaging rule (W-322, supersedes the W-321 per-machine rule)

Plugin code ships in the base. The authority is the workspace payload `99_System/09_Tools/runtime-plugins/` plus the generated lock; `build-base.py` copies it into `.obsidian/plugins/`. Plugin files are marked `-text` in `.gitattributes` so line endings never change their hashes. See `MDSE Bootstrap/README_MDSE Bootstrap.md` for how to change a version.
