# Translator Reference Precedence

## Working precedence

- The original translator primary reference establishes the baseline architecture and philosophy.
- Explicit later amendments supersede only the named rules they change.
- The 2026-09-27 relationship matrix/handoff is the current authority for relationship rules represented in this workspace.
- If two references conflict and neither explicitly amends the other, stop and review rather than guessing.
- Package-specific exceptions do not become global rules without explicit promotion.

## Workspace rule

Once a decision is represented as a settled Translation Rule note here, future changes should amend or supersede that rule explicitly rather than silently editing history.
