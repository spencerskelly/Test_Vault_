# MDSE v2 public synthetic vault — staging area

**Not ready for a separate testing repository or company data.**

This directory stages a freely publishable, entirely fictional Obsidian test vault. It exercises engineering concepts, not real product IP. The demonstrator is a fictional **Sample Instrument**, assembled from generic Control Unit, Sensor Unit, Power Unit and Operator Panel examples. All IDs and numeric properties are fabricated.

Obsidian can open this directory as a vault, but the full v2 plugin/base release, Canvas synchronization, and incremental-update engine are still **pending**. Do not claim v1 functional parity or importer compatibility yet.

Read [functional parity and public test contract](../../26_Definitions/V2%20Functional%20Parity%20and%20Public%20Test%20Vault.md). For now, read the [Sample Instrument](10_Model/Sample%20Instrument.md) and [model source](10_Model/Sample%20Instrument.sysml) side-by-side.

The eventual release gate requires first-open navigation, safe local edit/update, a deterministic zip, and inspection for proprietary data and credentials. Real EA CSV and QEAX files must remain outside all public repos.
